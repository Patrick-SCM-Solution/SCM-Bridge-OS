Odoo Playbook

Known gaps, automation backlog, and implementation guidance for the SCM Bridge OS Odoo instance.

Rev 1.0

This playbook tracks gaps between how SCM Bridge OS currently operates inside Odoo and how it should operate. Each gap card states the problem, its operational impact, the prioritised fix list, and a concrete solution path. Cards are ordered by priority — address red items first.

Known Gaps
Gap 001 — Odoo Workflow Automation
No Automated Action Triggers
🔴 Not started Effort: Low–Medium Owner: PM
Issue
No automated action triggers exist for key pipeline transitions. All handoffs are currently manual and memory-dependent — each step only moves forward if someone remembers to check.
Impact
  • Steps get missed when attention shifts to other projects
  • RFQ sends are delayed because there is no prompt after NDA closes
  • PM is a single point of failure for noticing completed NDAs and acting on them
Backlog — priority order
P1
NDA fully signed → Auto-create Send RFQ task assigned to PM
P2
Vendor replies to outreach → Auto-notify PM to step in and qualify
P3
RFQ sent → Auto-create Chase quote task with a due date
P4
Quote received → Auto-notify PM for review and approval
Solution
Use Odoo's native Automated Actions feature — no custom development needed.
Settings › Developer Mode › Technical › Automated Actions
First rule: ~1 hour. Remaining three rules: ~half a day total.
+
Additional gaps will be logged here as they are identified.
