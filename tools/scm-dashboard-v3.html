Data Sources ▼
project.project
Project Registry
→name — project title
→partner_id — client name
→stage_id — DR phase
→tag_ids — vendor scope tags
Used for: project list, phase badges, client names
project.task
Task & Allocation
→planned_hours — allocated time
→date_deadline — gate date
→stage_id — Backlog/WIP/Done
→user_ids — assignees
→description — outcomes + gate
Used for: allocation bars, deadlines, milestone list
account.analytic.line
Timesheet Logs
→unit_amount — hours logged
→employee_id — who logged
→date — when logged
→task_id — linked task
Used for: logged hrs, capacity bars, % complete
project.task.type
Stage Names
→name — Backlog, WIP, Done
→sequence — stage order
Used for: kanban stage mapping, gate status
project.milestone
Gate Milestones
→name — milestone label
→deadline — planned gate date
→is_reached — completed flag
→project_id — linked project
Used for: milestone timeline, overdue count
res.users + mail.activity
Team & Activities
→res.users.name — team member
→activity_type_id — email/call/todo
→date_deadline — activity due
→summary — activity note
Used for: team loading, follow-up actions
Custom fields planned: x_blocker_reason · x_gate_status · x_vendor_ids (project-scoped vendor assignment) · x_dr_phase (DR0–MP gate tracking)
